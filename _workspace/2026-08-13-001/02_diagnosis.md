## 지배 패턴 (겨냥 순서)

1. **C-8** 부정-긍정 대구 연쇄 ("단순히 A가 아니라 B" / "A에 그치지 않고 B") — **이 글의 최강 티이자 정량 지표가 못 잡는 구조 패턴.** 동일한 배타 수사 틀이 5문항 **전부**에 최소 1회씩, 문서 전체 8~10회 반복되어 문단 결론이 거의 이 틀로만 굴러간다. GPT 계열 산문의 결정적 시그니처.
   · 근거: "단순히 새로운 도구를 익히는 데 그치지 않고, 실제 업무와…"(문항1) / "AI를 단순한 검색이나 문서 작성 도구가 아니라 정보를 정리하고…"(문항3) / "새로운 AI 도구를 단순히 사용하는 사람이 아니라, 교육 운영의 목적과…"(문항3) / "단순히 격려하는 대신 현재 속도로는…"(문항4) / "교육 현장을 이해하는 것에서 그치지 않고, 자료와 운영 방식을…"(문항5) / "좋은 콘텐츠를 제공하는 것뿐 아니라 학습자가 실제로…"(문항5) / "개인의 경험이나 감에 맡기기보다 팀이 함께 참고할 수 있는…"(문항2)
   → 처방: 문서 전체에서 **1~2건만 살리고** 나머지는 직접 단언으로 환원한다("A가 아니라 B다" → "B가 핵심이다" / B만 서술). 특히 한 문항 안에서 두 번 나오면 반드시 하나는 푼다. 의미는 보존하되 배타 수사 틀만 해체.

2. **A-18** 관계절 직역형 긴 좌향 수식 (관형구 3중+ 중첩) — **정량 최대 카운트 21건.** 임계가 "한 문서 1회 초과 시 가산"인데 21건이면 문장 대부분이 해당한다. 핵 명사("~하는 사람", "~하는 것") 앞에 10~20어절짜리 수식이 쌓여 독자가 서술어에 닿기 전 작업기억이 소진된다.
   · 근거(정량): `relative_clause_nesting = 21`. 대표 예 — "장기적으로는 새로운 AI 도구를 단순히 사용하는 사람이 아니라, 교육 운영의 목적과 상황에 맞춰 어떤 도구와 방식을 적용할지 판단하고 운영 체계를 개선하는 **사람으로** 성장하겠습니다."(문항3 결말) / "반복되는 문제를 개인의 경험이나 감에 맡기기보다 팀이 함께 참고할 수 있는 기준으로 만드는 **것이** 품질을 안정적으로 유지하는 **방법임을** 배웠습니다."(문항2)
   → 처방: 관형구가 3어절 이상 중첩된 문장은 **마침표로 분할**하거나 후치 구문으로 푼다("~하는 사람으로 성장하겠습니다" → "~하고 싶습니다. 나아가 ~하는 사람이 되겠습니다"). 각 문항 결말 문장 5개가 모두 이 형태이므로 최소 3개는 분할.

3. **C-11** 연결어미 뒤 쉼표 [S1] — **★S1 트리거.** 분류 체계 단일 지표 최강 분리도(인간 4.10% vs AI 19.83%, 4.84배). 문서 15회 이상으로 6회+ S1 구간을 크게 초과. 한국어는 연결어미 '-고/-며/-면서'가 이미 호흡을 만들어 쉼표가 불필요한데, 이 글은 거의 모든 병렬 절에 자동으로 쉼표를 박았다.
   · 근거(정량): `ending_comma_rate = 0.25` (z=**+2.71**). 실제 — "익히는 데 그치지 않**고,**" / "세심하게 살피**고,**" / "따로 정리하**고,**" / "절반 이하로 줄였**고,**" / "우선순위를 먼저 정하**고,**" / "문제를 발견하**고,**" / "실제 학습에 활용하**면서,**" / "꾸준히 공유하**고,**" / "순서를 기준으로 대응하**고,**" / "재구성하**고,**" / "꼼꼼하게 관리하**고,**" / "확인하면**서,**" / "자료로 정리하는 것에서 나아**가,**"
   → 처방: 연결어미 직후 쉼표를 **일괄 제거**. 제거 후 호흡이 너무 길어지는 문장은 쉼표를 되살리지 말고 마침표로 절을 끊는다(2번 항목과 같은 손질로 처리).

4. **E-5** 쉼표 분절 평균 길이 (영어식 long sentence) — **문서 최강 z.** 인간 에세이 4.35어절 · AI 8.56어절 baseline에서 이 글은 **11.06어절**로 AI 평균조차 넘어선다. A-18과 "동시 위반 시 가중" 관계(taxonomy 명시)이며, 실제로 두 지표가 같은 문장들에서 겹친다.
   · 근거(정량): `comma_segment_length = 11.06` (z=**+3.19**), `comma_inclusion_rate = 0.43` (z=+0.94, C-12 인접). 대표 예 — "특히 진도가 크게 늦어진 동료에게는 단순히 격려하는 대신 현재 속도로는 이후 내용을 따라가기 어려울 수 있다는 점을 직접 이야기하고 학습 속도를 높일 필요가 있음을 전달했습니다."(문항4, 절당 12어절 이상)
   → 처방: 8어절 넘는 절은 마침표로 분할한다. 각 문단에 **15자 내외 단문 1개**를 의도적으로 넣어 리듬 표준편차를 만든다(E-1 동반 개선). 단, 단문만 늘어놓아 E-4(단문 일변도)로 넘어가지 않게 복문과 섞을 것.

5. **E-2** 진행형 '~고 있다' 자동 매핑 + 종결어미 단조 — 문서 8회 이상 "~하고 있습니다"가 반복되며, 상당수는 단순 시제로 환원해도 의미가 같다(진행 의미가 이미 문맥에 있음).
   · 근거: "진도를 확인하**고 있습니다**"(문항1) / "콘텐츠 제작에 활용하**고 있습니다**"(문항1) / "활용 범위를 넓혀가**고 있습니다**"(문항1) / "피드백을 빠르게 반영하**고 있습니다**"(문항2) / "업무 속도를 조절하**고 있습니다**"(문항2) / "효율화하는 단계에 **있습니다**"(문항3) / "현재 운영하**고 있는** 학습 커뮤니티"(문항4)
   → 처방: 절반가량을 단순 시제로 환원한다("확인하고 있습니다" → "확인합니다", "넓혀가고 있습니다" → "넓히는 중입니다"/"넓혔습니다"). **합쇼체는 유지**하되 종결부를 '~했습니다·~합니다·~하는 편입니다·~겠습니다'로 변주. 종결어미 '-습니다' 자체는 격식 유지상 불변.

6. **D-1 · A-2** 결산 pivot '이를 통해' + '~를 통해' 남발 — KatFish 검증 결산 lexicon 매치. D-1과 A-2에 동시 가산되는 항목이며, 문단 결론부를 기계적으로 여는 신호로 쓰이고 있다.
   · 근거(정량): `conclusion_pivot_count = 2` (lexicon 매치 '이를 통해'). 실제 '통해' 총 4회 — "이 경험**을 통해** 반복되는 문제를…"(문항2) / "**이를 통해** 완성도를 높이되…"(문항2) / "매니저 면담**을 통해** 확인했습니다"(문항2) / "**이를 통해** 교육의 품질은…"(문항5). 문항2 한 문항에만 3회 밀집.
   → 처방: 문서 전체 1건 이하로 줄인다. "이를 통해" → "그래서"·"덕분에"·삭제 후 직결, "면담을 통해 확인했습니다" → "면담에서 확인했습니다". **논리 연결 자체는 유지**하고 표지만 교체한다.

## 보존 지침 (이 글에서 건드리면 안 되는 것)
- **`### [문항 제목]` 5개 헤딩 — 한 글자도 변경 금지.** 채용 양식이 정한 문항이므로 C-3·C-10의 "학술·보고서 실제 절 제목은 보존" 예외가 그대로 적용된다. 헤딩 압축·개작·본문 흡수 전부 금지. 위의 A-7 1건이 이 헤딩에서 나온 것이므로 특히 주의.
- **수치·고유명사 불변**: 3년 / 약 4년 / 500~600장 / 주 1회 / 절반 이하 / SeSAC / AI 핀테크 PM / 피플에듀 / FAQ.
- **"~하겠습니다" 다짐형 마무리는 자소서 장르 관습 — 제거 금지.** D-6(완결 공식형 결말) 적용 대상 아님. 다만 문항1·3·4·5의 마지막 문단이 "부사구 + 긴 좌향 수식 + ~하겠습니다"라는 **동일 리듬으로 반복**되므로, 다짐은 남기되 그 앞의 수식 길이와 문장 수를 서로 다르게 만든다(A-18·E-5 처방으로 흡수).
- **문항 간 경험 재언급은 중복이 아니다.** "대학 시절 3년간 방과후 교습 봉사"(문항1·4·5), "학습 커뮤니티 운영"(문항1·4·5), "SeSAC 학습자료 재구성"(문항3·5)이 반복되지만 각 문항은 독립적으로 평가되므로 **삭제·통합 금지**. 표현만 문항마다 다르게 변주할 것.
- **1인칭 '저/저의'는 A-16 대상 아님** (pronoun_density 0.000으로 확인). 자소서에 필수인 주어이므로 생략 압박을 가하지 않는다. 다만 문항1·2·3·4 첫 문장이 모두 "저는/저의 X는 ~것입니다" 동일 문형인 점은 **C-4**(문단 첫 문장 요약 공식)에 해당하므로, 두괄식 자체는 유지하되 문형만 2개 이상 변주한다.
- **구체 사실은 손대지 않는다**: 재작업 비율 감소, 매니저 면담 확인, 이탈 후 커뮤니티 운영, 늦어진 동료에게 직접 이야기한 일, 현수막·명찰 디자인 — 자소서의 증거이므로 압축·추상화 금지.
- **D 계열 상투구 역방향 삽입 금지**: "괄목할 만한"·"의미가 크다"·"주목받았다" 류를 새로 넣지 않는다. 문장을 짧게 만들면서 hype 어휘로 채우는 것이 가장 흔한 역주행.

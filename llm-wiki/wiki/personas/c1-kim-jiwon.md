# C1 · 김지원 (28세) — 주 사용자

고밀도 직무형 부트캠프(KDT AI·SW·데이터 과정 3~6개월 차)에 참여 중인 **비전공 취업준비생**.

| | |
|---|---|
| 하루 | 강의 **6~8시간** 수강, 복습 가용 시간 **1~2시간** |
| Pain | 복습할 시간 부족, **버릴 것 판단 불가** → [[pp-3]] |
| Goal | 가용 시간 내 실무 핵심 우선 복습 후 취업 |
| 지불 상한 | **월 5,000원** (무료 대체재 다수) 🟡 |
| 현재 대안 | 노션 수기 정리, 클로바노트 녹음 |

## 왜 이 사람이 표적인가
비전공자는 **지식 체계가 확립되어 있지 않아 스스로 약점을 선별하지 못한다.** 따라서 외부 실무 전문가(강사)의 명시적 판단 신호가 복습의 기준점이 되어야 한다 🟡.
→ 이것이 [[provenance-vs-intelligence]]의 인간적 근거다.

## 전환 동인
- **Push:** 하루 8h 연강 후 복습 시간 1~2h 불과
- **Pull:** 강사 실무 강조점만 우선 추출
- **Anxiety 해소:** Audio Provenance — 태그 클릭 시 1:1 오디오 즉시 재생

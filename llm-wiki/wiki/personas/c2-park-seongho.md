# C2 · 박성호 (45세) — 주 지불자

교육 과정 기획·예산 집행·취업률 관리를 담당하는 **KDT 훈련기관 운영실장**.

| | |
|---|---|
| Pain | KDT 취업률 급락(**54.2%** 🟢), 중도이탈 **사후 인지** → [[pp-k1]] |
| Goal | 수강생 취업률 방어 및 기관 평가 등급 유지 |
| 지불 | 기관 B2B 라이선스 **연 1,000만 원 안팎** 🔴 → [[h-b2b]] |
| 현재 대안 | 강사 사후 면담, 수료 후 취업 집계 (통제 불가) |

## 이 페르소나가 뒤집은 가정 ★

> **기관은 학생용 학습 앱에 예산을 쓰지 않는다.**

2년간 8.4%p 하락한 취업률을 방어하고 중도 이탈자를 사전 감지하는 **"운영 성과 관리 대시보드"** 일 때 비로소 예산 집행이 성립한다 🟡.
→ [[overturned-assumptions]] · 이것이 콕집 B2B 메시징 전체를 규정한다.

## 개인 지불자와의 관계 — 112배
[[c1-kim-jiwon]]의 지불 상한은 월 5,000원, 이 사람의 예산은 연 1,000만 원. **112배 격차**가 콕집의 유통 구조를 결정한다 → [[two-sided-payer-gap]]

## 막고 있는 게이트

# Grounding Matrix — VPS v2.0 §6

**최종 산출물이 스스로 매긴 11개 주장의 근거 수준.** 원본 그대로 승계한다.

| # | 핵심 가치 주장 | 등급 | 근거 |
|:-:|---|:-:|---|
| 1 | 학습자는 남은 시간에 무엇을 버릴지 결정하고 싶어 한다 | 🟡 | 결핍 점수 1위 (AOS 3.00, DOS 3.00) |
| 2 | KDT 취업률 하락으로 기관 성과 위기감 증가 | 🟢🟡 | 공시 통계 🟢 기반 기관 심리 추론 🟡 |
| 3 | 경쟁 8개사 중 '버릴 것'을 선언한 도구는 없다 | 🟢 | 8개사 기능·가치 선언 실사 완료 |
| 4 | 무료 번들로 단순 전사·요약 가격은 0원에 수렴 | 🟢 | 네이버 300~600분 무료, Google 무료 배포 |
| 5 | 단순 시간 입력 UI만으로는 차별성 확보 불가 | 🟡 | 프롬프트 한 줄로 재현 가능한 구조 |
| 6 | 강사 발화 출처가 AI 요약보다 신뢰도 높을 것 | 🟡 | 비전공자 권위 의존 심리 분석 |
| 7 | 오디오 타임스탬프 동기화가 탐색 시간을 단축 | 🟡 | 클릭-재생 1:1 매핑 UI 구조 |
| **8** | **강사 실무 강조 발화가 충분한 빈도로 발생** | **🔴** | **최우선 선행 가설 1 — [[h-signal]]** |
| **9** | **수강생이 우선순위를 신뢰하고 행동을 변경** | **🔴** | **핵심 선행 가설 2 — [[h-trust]]** |
| **10** | **특정 시점에 유료 지불 의사(WTP)가 발생** | **🔴** | **수익성 가설 — [[h-conv]]** |
| **11** | **훈련기관이 도입 예산을 배정** | **🔴** | **B2B 가설 — [[h-b2b]]** |

## 읽는 법

**1~7은 제품을 설계할 수 있게 하고, 8~11은 제품을 만들어도 되는지를 정한다.**
8~11이 전부 🔴이므로 **PRD 작성이 동결돼 있다.**

# H-Signal — 신호 밀도 (최우선 검증 병목)

## 가설
실제 직무형(KDT 등) 강의에서 강사가 **실무 중요도·현업 관행·면접 빈출을 직접 언급하는 구어체 강조 신호가 정기적으로 발생한다.**

## 무너지면 무엇이 무너지는가

> **가치 B 전체가 붕괴한다.** 신호가 없으면 [[provenance-vs-intelligence]]는 근거 없는 주장이 되고, 04~07 사슬이 전제한 문제 정의도 함께 무효화된다.

이것이 **이 저장소에서 가장 값싸고 가장 결정적인 실험**인 이유다 — 3일, 0원.

## 검증 설계

| | |
|---|---|
| **방법** | KDT 실제 강의 녹취 3~5개(15~25시간 분량)에서 강사 구어체 실무 강조 발화 **전수 카운팅** |
| **기간·비용** | 3일 · 0원 |
| **임계값** | 시간당 평균 **2.0회 이상 → 가치 B 확정** · 0.5~1.9회 → 신호 정의 범위 조정 · **0.2회 이하 → 가치 B 기각** |
| **미달 시** | 가치 B 폐기 → **채용공고 기반 산업 기술 수요**를 1차 근거로 하는 대체 VP로 전면 피벗 |

> ※ 이 임계값은 시장 통계나 확정 KPI가 아니라 **가설 유효성 판단을 위해 설정한 실험용 값**이다.

# 두 가치사슬 비교 — 마진 레버가 서로 정반대 방향

| | AX/DX 교육 | 자율주행 완성차 |
|---|---|---|
| **병목** | ② 운영·생산 — **강사 시간** | ② 운영·생산 — **검증 원가** |
| **마진 레버 방향** | 서비스업 → **제품업 쪽으로** (사람 일을 자산으로) | 제품업 → **서비스업 쪽으로** (판매 후 데이터 사슬로) |
| **축적 루프** | 서비스(질문 로그) → 투입(콘텐츠 개선) | 서비스(필드 데이터) → 투입(엣지케이스) |
| **원가 통제 수단** | 모델·API 추상화 계층 | 컴퓨트 이중 소싱·하드웨어 추상화 |

## 두 사슬이 같은 명제로 묶이는 지점

> **원가의 결정권을 외부 공급자와 사람의 시간에서 되찾아야 한다** 🟡 → [[ksf-new-entrant]] #5

두 시장 모두 공급자 교섭력 **4/5**이고, 병목이 둘 다 ②에 있으며, 둘 다 원가 문제다. 방향만 반대다.

## 콕집에 대한 함의
콕집은 **교육 쪽 사슬을 물려받았으므로 "서비스업 → 제품업" 방향**이 맞다. 그 구체적 형태가 [[reuse-margin-rule]]이다.

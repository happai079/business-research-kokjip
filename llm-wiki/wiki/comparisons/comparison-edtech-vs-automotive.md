# AX/DX 교육 vs 자율주행 — 같은 '저수익'인데 원인이 거울처럼 반대다

> **A는 문이 열려 있어서 가난하고, B는 문을 잠그는 값이 비싸서 가난하다.**

| 구분 | A · AX/DX 교육 (23/25) | B · 자율주행 (19/25) |
|---|---|---|
| **저수익의 근본 원인** | **장벽이 없어서** — 누구나 들어와 초과 이익을 즉시 분산 | **장벽이 비싸서** — 벽을 세우고 유지하는 비용이 이익을 먹음 |
| **지배적인 힘** | 신규 진입 + 대체재 + 구매자 (**외부에서 밀려온다**) | 기존 경쟁 강도 (**내부에서 서로 깎는다**) |
| 필요 자본 | 거의 없음 | 조 단위 |
| 퇴출 난이도 | 매우 쉬움 (그래서 진입도 끝나지 않음) | 매우 어려움 (그래서 과잉 설비가 남음) |
| 시장 성장률 | 매우 높음 | 성숙·정체 |
| 성장과 수익 | **성장이 이익으로 남지 않는다** | **성장 자체가 없다** |
| 이익 변동 트리거 | 성장률 둔화 (그 순간 경쟁 강도 폭발) | 가동률 하락 (그 순간 가격 전쟁) |
| 사이클 속도 | 6~12개월 (모델 세대 교체) | 5~10년 (차량 개발 주기) |

## 학습 포인트

**매력도를 결정하는 것은 성장률도 장벽의 높이도 아니라, 벌어들인 돈을 누가 가져가는지의 구조다** 🟡.

- 성장률이 높은 산업이 좋은 산업은 아니다 → A에서 확인
- 진입장벽이 높은 산업이 좋은 산업은 아니다 → B에서 확인

콕집이 속한 시장은 A형이다. 따라서 **성장률을 근거로 한 낙관은 이 저장소에서 금지된다.**

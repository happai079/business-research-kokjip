# 가치사슬 (Value Chain)

기업 내부 활동을 **주요활동**(투입·운영·산출·마케팅영업·서비스)과 **지원활동**(인프라·인사·기술개발·조달)으로 분해해 **마진이 어디서 나오고 어디서 막히는지** 찾는다.

## 콕집 적용 — 세 가지 진단

### ① 병목 = 판정 구간
녹음·전사·요약은 무료 도구가 장악했으므로, **유료 가치의 근거는 오직 '실무 중요도 판정' 구간 하나**에만 존재한다 🟡.

### ② 마진 스케일링 규칙
> **"동일 커리큘럼에서 생성된 1회의 중요도 판정 결과를 몇 명의 수강생이 재사용(Reuse)하는가"가 영업 마진율을 결정한다** 🟡

API 추론 비용이 사용량에 비례하므로, 마진은 기능이 아니라 **재사용 배수**의 함수다. → [[reuse-margin-rule]]

### ③ 유일한 비가역적 자산 루프 [서비스 ⑤ → 투입 ①]
수료생의 **취업 결과 데이터(라벨)** 가 누적되어 강사 발화 신호의 가중치를 교정하는 피드백 루프. 경쟁사가 단기간에 복제할 수 없는 고유 자산 🟡.
단, 확보 시점이 **9~12개월 후**라 현 단계 VP에서는 제외됐다. → [[judgment-basis-candidates]]

### 무거운 지원활동 — 데이터 거버넌스
타인의 저작물(강의)과 제3자 음성을 다루므로 **법적 리스크 방어가 사업 영위의 선결 조건** 🟢. → [[recording-consent-patterns]]

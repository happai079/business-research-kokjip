# 참조 사례 — 자율주행 중심 완성차 기업의 가치사슬

## 가치가 새는 지점
자율주행 검증 비용(실도로 주행·시나리오 작성·회귀 테스트) · 차종별 중복 개발 · 리콜/보증 수리 · 공장 가동률 미달과 재고 · 딜러 유통 마진 잠식 · 부품 이중 소싱 단가 상승(공급자 힘 방어의 대가)

## 마진이 생기는 지점
플랫폼·모듈 재사용 · **OTA로 처리하는 리콜과 기능 개선** · SW 구독·기능 매출(증분 원가 ≈ 0) · 예측 정비 · 플릿 마일당 매출

> **핵심 문장:** 물리 사슬은 이미 수십 년간 최적화되어 개선 여지가 얇다. **새 마진은 판매 이후에 작동하는 데이터 사슬에서만 나온다.**

## 순환 고리
투입(엣지케이스 **선별** 수집) → 운영(시뮬레이션 검증) → 산출(단계적 OTA) → 서비스(필드 데이터 회수) → 투입.
**이 순환의 회전 속도가 곧 성능 격차의 원천.** 전량 수집은 원가를 감당할 수 없으므로 **"같은 상황의 10만 번째 데이터는 가치가 0에 가깝다"** → 선별 트리거 설계가 핵심.

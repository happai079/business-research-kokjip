# 콕집 현재 판정 — 2026년 8월

> **현재 상태는 "개발에 착수할 준비가 완료된 상태"가 아니라 "핵심 가치 가설을 소규모 실험으로 실측해야 하는 상태"다.** — [[vps-v2-0-rooted]] §11

## 확실히 확인된 것 🟢

1. 부트캠프 수강생에게 '복습 시간 부족'과 '버릴 것 선별의 어려움'은 **실재하는 문제**다.
2. 빅테크 무료 번들로 **단순 전사·요약 기능의 시장 가격은 0원**이다. → [[free-bundle-erosion]]
3. 경쟁 8개사 중 **'강사 발화 출처 기반 우선순위(뺄셈)'를 선언한 사업자는 없다.** → [[competitor-value-declarations]]

## 가장 유력한 가설 🟡

**"AI의 자의적 요약이 아닌, 강사의 구어체 실무 강조 발화(Provenance)를 근거로 복습 우선순위를 제시하고 원천 오디오로 즉시 연결하는 것"** 이 유일하게 유효한 차별화 경로.
→ [[provenance-vs-intelligence]]

## 게이트 판정 (PRD 착수 조건)

- **Go:** 신호 밀도 시간당 평균 **≥ 2.0회** 확인 + A/B에서 신뢰·우선순위 채택 확인 → 즉시 PRD 작성
- **Pivot:** 신호 밀도 **≤ 0.2회/h** → 가치 B 폐기, 채용공고 기반 대체 VP로 전면 피벗

## 그리고 이 판정 밖의 문제

위 게이트는 **가치 B가 성립하는지**만 묻는다. [[post-ai-learner-pain-hub]]는 **가치 B가 성립하더라도 범용 AI 사정권 안**이라고 본다. 이 충돌은 게이트 실험으로 해소되지 않는다.
→ [[ctr-01-appendix-a-vs-vps]]

# 케이스 01 — 콕집

창업 교육 워크숍에서 정의한 아이템. **챕터 01~08 전부가 이 하나의 서비스를 대상으로 한다.**

| 항목 | 내용 |
|---|---|
| **Before → After** | 강의가 매일 쌓여 복습을 미루고 무엇부터 볼지 몰라 처음부터 다시 뒤짐 → 우선순위 높은 것만 복습하고 **남은 시간을 취업 준비에 재배분** |
| **핵심 가치** | 학습 내용 중 **현직자 인사이트로 우선순위를 정해** 복습을 도움 |
| **주 표적 / 주 지불자** | 국비 부트캠프 수강생([[c1-kim-jiwon]]) / **국비 훈련기관**([[c2-park-seongho]]) — **둘이 분리된다는 것이 이 사업의 지배 조건** |
| **원재료 공급자** | 현직자 강사([[c3-lee-junhyuk]]) — **거부권 보유** |

## 3자 생태계

```text
     [이준혁 (강사 C3)] ──(원재료 / 권위)──┐
              │                              │
              ▼ (표준 opt-in 동의)          ▼ (실무 강조 발화)
     [박성호 (기관 C2)] ──(차수 일괄배포)──> [김지원 (수강생 C1)]

```

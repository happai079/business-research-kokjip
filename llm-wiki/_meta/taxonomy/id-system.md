# ID 체계

원본 문서가 이미 쓰고 있는 식별자를 위키가 **그대로 승계**한다. 위키가 새 ID를 발명하는 경우는 원본에 ID가 없는 객체(엔티티·개념)뿐이다.

| 접두사 | 대상 | 원본 출처 | 예시 |
|---|---|---|---|
| `PP-*` | 콕집 트랙 Pain Point (17건) | Ch05·Ch06 | `PP-3`, `PP-6`, `PP-K1`, `PP-N1`, `PP-E2` |
| `P-*` | 부록 A 트랙 Pain (14건) | 부록 A-1 | `P-03`, `P-08`, `P-09` |
| `C1~C3 / A1~A3 / E1~E3 / N1~N3` | 페르소나 스펙트럼 12종 | Ch05 | `C1`(김지원), `C2`(박성호) |
| `L1~L7` | 학습자 세그먼트 | Ch04 | `L1` 국비 부트캠프 |
| `K1~K7` | KDT 거시 지표 | 00 기준 리서치 §1-1 | `K3` 취업률 추이 |
| `P1~P7` | 청년층 모집단 지표 | 00 기준 리서치 §1-2 | `P5` 장기 미취업 |
| `KSF-1~6` | 신규 진입자 핵심 성공 요인 | Ch03 | `KSF-6` 원재료 접근권 |
| `H-*` | 미검증 가설 | 00 §7-2 · VPS §7 | `H-Signal`, `H-Trust`, `H-Conv`, `H-B2B`, `H-Match` |
| `GM-*` | Grounding Matrix 주장 번호 | VPS v2.0 §6 | `GM-8` |
| `CTR-*` | 모순 기록 **(위키 신규)** | — | `CTR-01` |
| `Q-*` | 열린 질문 **(위키 신규)** | — | `Q-01` |

## 접두사 충돌 주의

`P-*`(부록 A Pain)와 `P1~P7`(청년층 지표)은 **원본에서 이미 형태가 겹친다.** 위키에서는 다음으로 구분한다.

- 부록 A Pain: 항상 **두 자리 제로패딩** — `P-03`, `P-08`
- 청년층 지표: 하이픈 없음 — `P1`, `P5`

## 새 ID를 만들 때

1. 원본에 이미 있는지 먼저 확인한다.
2. 없으면 위키 신규 접두사(`CTR-`, `Q-`)만 사용한다.
3. 원본 객체에 임의로 ID를 부여하지 않는다 — 원본이 갱신되면 충돌한다.

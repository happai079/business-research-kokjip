# 부록 A — 범용 AI 시대의 학습자 Pain 제로베이스 재탐색

**이 부록은 챕터 01~08과 분리된 별도 트랙입니다.** 앞 챕터의 결론을 이어받지 않고, 오히려 **앞 챕터가 전제한 문제 정의 자체를 폐기한 상태에서** 다시 시작합니다.

## 왜 분리했는가

챕터 01~08은 **「콕집」이라는 하나의 서비스를 관통하는 분석**입니다. 각 챕터가 앞 챕터의 산출물을 입력으로 받으므로, 문제 정의가 흔들리면 08장까지의 사슬 전체가 흔들립니다.

그런데 08장에서 다음이 확인됐습니다.

## 이 부록의 한 줄 결론

**범용 AI 시대에 희소해진 것은 지식이 아니라 「이 사람이 실제로 무엇을 어떻게 했는지의 기록」입니다.**

AI는 설명하고, 요약하고, 계획하고, 가르칩니다. 그러나 **나를 실제로 하게 만들지 못하고**(행동), **내가 했다는 것을 남에게 믿게 하지 못합니다**(신뢰). Pain 14건 중 살아남은 것들이 전부 이 두 항목에 몰려 있습니다 → [인벤토리 §5](./pain-inventory-post-ai-era.md#5-살아남은-것을-묶으면-세-덩어리다)

## 근거의 한계 — 먼저 읽어야 하는 것

**이 부록은 전부 데스크 리서치이며 1차 인터뷰가 0건입니다.** Pain의 존재는 공개 자료로 확인했지만 **강도·빈도·지불 의사는 확인하지 못했습니다.** 판정표의 🔴 항목이 그 자리입니다.

**따라서 이 부록의 판정은 "무엇을 인터뷰해야 하는가"의 목록이지, "무엇을 만들어야 하는가"의 결론이 아닙니다** → [인벤토리 §7](./pain-inventory-post-ai-era.md#7-다음-단계--이-부록이-답하지-못한-것)

**A-2에서 확인된 가장 큰 공백** — 살아남은 Pain 중 **지불 의사가 실증된 것은 P-09(증명)와 P-08(완주) 둘뿐**이고, **P-03·P-05(역량이 안 남는다)는 돈이 흐른 사례를 하나도 찾지 못했습니다** → [A-2 §7](./ai-substitutability-and-viability.md#7-불확실-항목--근거를-확보하지-못한-것)

**A-3의 결론은 "무엇을 만들자"가 아닙니다.** 서비스 방향 8개는 전부 **미검증 가설**로 두었고, 대신 **한 달 안에 끝나는 검증 3건과 사전 임계값**을 정했습니다. 콕집 존폐도 지금 결정하지 않으며, **검증 결과가 결정 트리에 기계적으로 답을 내도록** 기준만 못박았습니다 → [A-3 §5](./opportunity-map-and-validation-plan.md#5-콕집-유지--피벗--폐기-판단)
